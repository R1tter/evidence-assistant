# Evidence Assistant

Read the approved scope and implementation plan in `docs/superpowers/` before implementation.
Follow `docs/engineering-quality.md` and `docs/ux-design.md` for every change.
Use `.agents/skills/ui-ux-pro-max/SKILL.md` for interface design and UX review.

Build simple, cohesive modules with explicit contracts. Keep core independent of UI and transport adapters. Enforce quality gates and test observable behavior.
Do not include proprietary code, documents or internal architecture from employers or Black Box.
Keep secrets out of source control. Demo and baseline CI must run without external API credentials.
Report only executed verification results. Distinguish extractive demo answers from LLM-generated answers and evidence checks from semantic correctness.
